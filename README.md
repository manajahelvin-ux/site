# Site Comparateurpro

## Lancer le site localement

Depuis le dossier du projet :

```sh
python3 -m http.server 4000
```

Ouvrez ensuite `http://localhost:4000` dans un navigateur.

## Référence et limites

La structure, certains textes, les styles, les polices et trois illustrations proviennent de l'archive hors ligne Allianz présente dans le dépôt. Cette archive est datée du **15 juin 2024** : elle peut différer du site Allianz actuel. Les photographies et le logo utilisés par le site Comparateurpro sont locaux. L'archive indique que son contenu appartient à Allianz France et qu'elle est fournie pour un usage personnel/hors ligne ; vérifiez les droits avant toute publication.

Les services et formulaires de devis Allianz ne sont pas connectés. Les rubriques sans destination locale ne sont pas des liens actifs. Aucun formulaire de devis ni espace client Comparateurpro n'est configuré.
